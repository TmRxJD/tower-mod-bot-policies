# The Tower Mod Bot policies

Standalone public GitHub Pages site for The Tower Mod Bot. The bot itself is a private tool for the designated moderation team of the official The Tower Discord, with any affiliated sister-server deployment requiring the operator's explicit authorization. It is not available for public installation in other servers. Members can still use community features enabled for them. Only public policy content belongs here: never add bot source, logs, databases, transcripts, configuration, or secrets.

- Site: https://tmrxjd.github.io/tower-mod-bot-policies/
- Privacy policy: https://tmrxjd.github.io/tower-mod-bot-policies/privacy/
- Terms of service: https://tmrxjd.github.io/tower-mod-bot-policies/terms/

GitHub Pages publishes the root of `main`. Edit the HTML and CSS directly; no build system or dependencies are needed. Update the effective/last-updated dates when changing policies. Operated and maintained by `tmrxjd`, used by Discord moderators. Privacy requests may go to `tmrxjd`, any official The Tower Discord moderator, or a private ticket in that server, including requests to modify bot-held data.

Enter the two policy URLs in the matching fields in the Discord Developer Portal. Publishing this site does not complete Discord verification or change bot data-handling behavior. Operators must honor deletion requests across local databases, Appwrite copies, transcript files, and backups. Review operational retention, encryption at rest, provider agreements, and user-facing policy access as part of the verification application.

The policy was based on the bot source on October 7, 2026: moderation/profile records, account links, watchlist transcript backups, event submissions, polls with voter IDs, Groq text/image processing, and evaluation sessions with a seven-day default expiration. It also describes the custom codec's participant/message aliases and message-text URL/channel-marker replacement in supported AI workflows. This is pseudonymization and minimization, not encryption or complete anonymity. Keep the policy aligned with deployed practices.
