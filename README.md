# The Tower Mod Bot policies

Standalone public GitHub Pages site for The Tower Mod Bot. Only public policy content belongs here: never add bot source, logs, databases, transcripts, configuration, or secrets.

- Site: https://tmrxjd.github.io/tower-mod-bot-policies/
- Privacy policy: https://tmrxjd.github.io/tower-mod-bot-policies/privacy/
- Terms of service: https://tmrxjd.github.io/tower-mod-bot-policies/terms/

GitHub Pages publishes the root of `main`. Edit the HTML and CSS directly; no build system or dependencies are needed. Update the effective/last-updated dates when changing policies. Contact: `tmrxjd` on Discord.

Enter the two policy URLs in the matching fields in the Discord Developer Portal. Publishing this site does not complete Discord verification or change bot data-handling behavior. Operators must honor deletion requests across local databases, Appwrite copies, transcript files, and backups. Review operational retention, encryption at rest, provider agreements, and user-facing policy access as part of the verification application.

The initial policy was based on the bot source on October 7, 2026: moderation/profile records, account links, watchlist transcript backups, event submissions, polls with voter IDs, Groq text/image processing, and evaluation sessions with a seven-day default expiration. Keep the policy aligned with deployed practices.
